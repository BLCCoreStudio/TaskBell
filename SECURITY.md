# Security Policy

## Supported versions

TaskBell is in early development. Security fixes are applied to the latest code on the `main` branch until stable releases begin.

## Reporting a vulnerability

Please do not publish suspected vulnerabilities, sensitive command lines, credentials, tokens, or private environment information in a public issue.

Use GitHub's private vulnerability reporting feature when it is available for this repository. If private reporting is unavailable, contact the repository owner through the contact method listed on the BLCCoreStudio GitHub profile and include only the minimum information needed to establish a private reporting channel.

We will acknowledge actionable reports as soon as practical and coordinate disclosure after a fix is available.
